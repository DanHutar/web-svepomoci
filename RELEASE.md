# Web svépomocí 1.2.0

- Nové názvy: **web-svepomoci-plugin** a **web-svepomoci-sablona**.
- Aktualizace obou součástí z vydání tohoto GitHub repozitáře přes běžnou administraci WordPressu.
- Tlačítko **Web svépomocí → Zkontrolovat aktualizace**.
- Obsahuje propojení hlavičky a patičky s **Vzhled → Menu** pomocí `[aiwp_menu location="primary"]` a `[aiwp_menu location="footer"]`.

Při přechodu ze starého AI Web / AI Web Studio nahrajte oba instalační ZIPy z příloh tohoto vydání a potvrďte nahrazení stávající verze. Použijte **web-svepomoci-plugin.zip** v Pluginy a **web-svepomoci-sablona.zip** ve Vzhled → Šablony. Technické složky zůstávají `ai-web-studio` a `ai-web`, aby zůstala zachována aktivace, nastavení a přiřazení menu. Uložené HTML, CSS, JS a SEO zůstávají v databázi.

První instalace verze s aktualizacemi je ruční; následující vydání už nabídne WordPress. Automatické instalování bez kliknutí zůstává na vaší volbě v administraci. **Source code (zip)** obsahuje celý vývojový projekt a není instalační balíček pro WordPress.
