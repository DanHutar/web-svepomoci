# Web svépomocí 1.9.1

- V **Web svépomocí → Soukromí a cookies** přibyl přepínač **Souhlas spravuje externí plugin** pro použití například s Complianz.
- Externí režim vypíná naši lištu, tlačítko i odkaz v patičce, její CSS/JS a vydávání měřicích skriptů. Původní nastavení uchová; kódy ani souhlasy nepřenáší do externího pluginu. Při návratu návštěvník provede novou volbu.
- Oba instalační ZIPy obsahují složku **prompty** se sedmi textovými soubory: návod, společné CSS, stránka, header, footer, informace o cookies a ochrana osobních údajů.
- Prompty zachovávají společné styly a menu WordPressu. Informační stránky vyžadují skutečné podklady a rozlišují ruční dokumenty od dokumentů spravovaných Complianz.

Od verze 1.2.0 aktualizujte běžným tlačítkem ve WordPressu; kontrolu vyvoláte přes **Web svépomocí → Zkontrolovat aktualizace**. Ze starších verzí nahrajte instalační ZIPy ručně a potvrďte nahrazení. Po aktualizaci vymažte případnou cache webu.

Přepínač Complianz nenastavuje; správu souhlasu a měření v něm dokončete samostatně. Po přepnutí vymažte cache a ověřte web v novém anonymním okně. [Návod a omezení](https://github.com/DanHutar/web-svepomoci/blob/main/docs/soukromi-cookies.md). [Textové prompty](https://github.com/DanHutar/web-svepomoci/tree/main/prompty).

Podrobnosti: [Ověření funkcí](https://github.com/DanHutar/web-svepomoci/blob/main/docs/overeni.md).

Použijte přílohy **web-svepomoci-plugin.zip** a **web-svepomoci-sablona.zip**. **Source code (zip)** není instalační balíček WordPressu.
