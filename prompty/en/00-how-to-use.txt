BYYOURSELF — TEXT PROMPTS FOR AI

These UTF-8 text files are included in the plugin and theme installation ZIPs. Keep the original ZIP for WordPress installation and extract a copy to read the prompts in any text editor.

1. Start with 01-shared-design.txt. Select a font under Website design and create shared CSS.
2. Use 02-page.txt for each page, 03-header.txt for the shared header and 04-footer.txt for the shared footer.
3. Use 05-cookie-information.txt and 06-privacy-notice.txt for informational pages. Collect real facts about the operator and services first. Do not let AI invent providers, retention periods or claims of legal compliance.
4. Copy the chosen file into your AI and replace the bracketed fields. Write UNKNOWN when you do not know an answer. Do not send passwords, secret keys or real customer records.
5. Paste HTML into Content, CSS into Design and JS into Behaviour in our editor. Omit ``` code fences and never paste PHP. Shared CSS belongs only in ByYourself → Website design → Shared CSS. Put the SEO title and meta description in the page's separate SEO panel.
6. Enable AI editor content and save. Save headers and footers in their shared editors instead of repeating them on each page. Check both the preview and the real website, including mobile and keyboard navigation.

LANGUAGES
ByYourself → Language controls the plugin/theme interface, public labels and requested AI content language separately. The interface can be English while the website copy is Czech. These preferences do not translate saved content or change WordPress itself. For downloaded prompts, fill in the requested output language yourself. English and Czech prompt folders contain the same types of tasks.

MENUS
Create navigation in Appearance → Menus and assign it to primary or footer. Ask AI to use [aiwp_menu location="primary"] or [aiwp_menu location="footer"], not manually duplicated navigation links.

CONSENT AND COMPLIANZ
Built-in consent management is disabled and its administration screen is removed. Configure consent, tracking and consent controls in an external plugin such as Complianz. Stored settings are preserved but inactive; scripts and consent records are not transferred. Clear website/CDN caches after upgrading. Do not add tracking or a new banner to AI page, header or footer code.


Do not put tracking code in pages, headers or footers. Our HTML editor only expands aiwp_menu. Keep documents generated by Complianz on standard WordPress pages with the AI editor disabled; link to them from your footer menu. Do not paste Complianz document shortcodes into our HTML field.
